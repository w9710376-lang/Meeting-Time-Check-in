# แผนงาน: โหมด Split Screen (จอคู่) — แสดง QR Code คู่กับ Executive Dashboard แบบเรียลไทม์

แผนการออกแบบหน้าจอสำหรับการเปิดขึ้น **จอทีวีหรือโปรเจกเตอร์ขนาดใหญ่หน้าห้องประชุม** เพื่อให้พนักงานสามารถเดินเข้ามาสแกน QR Code เช็คอินเข้าประชุมเช้าได้อย่างสะดวก ในขณะที่ผู้บริหารและผู้เข้าร่วมประชุมสามารถมองเห็นสถิติ ตัวเลขผู้เข้าร่วม และตัวละคร 3D ภายในอัฒจันทร์อัปเดตแบบเรียลไทม์ทันทีที่มีการสแกน

---

## 1. การจัดวางหน้าจอ (Split Screen Layout Architecture)

หน้าจอจะแบ่งออกเป็น 2 ฝั่งหลักในอัตราส่วนที่เหมาะสมกับจอ Widescreen 16:9 / 1080p / 4K ของทีวีและโปรเจกเตอร์:

```
+---------------------------------------------------------------------------------------------------+
|  [Header] Executive Dashboard — Live Meeting Mode        [เลือกแผนก] [โหมดเต็มจอ] [สลับมุมมอง]    |
+---------------------------------------------------+-----------------------------------------------+
|  << ฝั่งซ้าย (~40%): Live QR Code Kiosk Station   |  >> ฝั่งขวา (~60%): Real-Time Dashboard Stats  |
|                                                   |                                               |
|  1. นาฬิกาดิจิทัลขนาดใหญ่ (HH:mm:ss)               |  1. สรุปตัวเลข KPI 4 ช่อง                     |
|  2. แท็บสลับแผนก (Department Selector)            |     (ทั้งหมด / เข้าประชุม / ติดภารกิจ / รอสแกน) |
|  3. ป้ายช่วงเวลาเข้าประชุม (เช่น 07:30 - 07:45 น.) |  2. การ์ดอัฒจันทร์ 3D (Morning Meeting Card)   |
|  4. กรอบ QR Code ขนาดใหญ่ (ระยะสแกน 2-3 เมตร)     |     (ตัวละคร 3D ปรากฏทันทีแบบ 1:1 เมื่อสแกน)    |
|     - ก่อนเวลา: แสดงกล่องเตือนรอเปิด 07:30 น.     |  3. พนักงานที่ยังไม่เช็คอิน (รายชื่อจะหายสดๆ) |
|     - ในเวลา: QR Code ชัดเจน พร้อมรีเฟรชทุก 10 วิ  |  4. ลีดเดอร์บอร์ดคนสแกนล่าสุด (แสดงเวลา & คะแนน) |
|     - หมดเวลา: ปิด QR และแสดงแจ้งเตือนหมดเวลา     |                                               |
|  5. สรุปความคืบหน้าของแผนก (สแกนแล้ว/คงเหลือ)     |                                               |
+---------------------------------------------------+-----------------------------------------------+
```

---

## 2. รายละเอียดส่วนประกอบแต่ละฝั่ง

### ฝั่งซ้าย: Live QR Code Kiosk Station (สำหรับพนักงานเดินสแกน)
1. **นาฬิกาดิจิทัลความละเอียดสูง**: แสดงเวลา ชั่วโมง:นาที:วินาที ขนาดใหญ่ ชัดเจน อ่านง่ายจากระยะไกล
2. **ตัวเลือกแผนก (Department Bar)**:
   - ปุ่มเลือกแผนก (เช่น IE, QA, PE) เพื่อสลับ QR Code ของแผนกนั้นทันที
   - หากผู้ใช้เป็นหัวหน้าแผนก (Scoped Dept) จะล็อกแผนกให้อัตโนมัติ
3. **ระบบควบคุมความปลอดภัยของ QR Code ตามเวลาจริง**:
   - **ก่อนเวลา (Before 07:30 น.)**: ซ่อน QR Code และขึ้นกล่องสีเหลือง *"ยังไม่ถึงเวลาเปิดเช็คอิน รอเปิด 07:30 น."*
   - **ระหว่างเวลา (07:30 - 07:45 น.)**: แสดงภาพ QR Code คมชัดสูง ขนาดใหญ่ พร้อมระบบเปลี่ยน Token อัตโนมัติทุก 10 วินาที เพื่อป้องกันการส่งรูปถ่ายต่อกัน
   - **หลังเวลา (After 07:45 น.)**: ปิด QR Code อัตโนมัติทันที
4. **สรุปความคืบหน้ารายแผนก**: แถบความคืบหน้า (Progress bar) สแกนแล้วกี่คน จากจำนวนทั้งหมด

### ฝั่งขวา: Real-Time Executive Dashboard (สำหรับผู้บริหารและที่ประชุม)
1. **KPI Cards สรุปสด**:
   - พนักงานที่เปิดใช้งาน
   - เข้าร่วมประชุมเช้า (สีเขียว)
   - ไม่เข้าร่วม (ติดภารกิจ) (สีแดง)
   - ยังไม่สแกน QR Code (สีเทา)
2. **3D Miniature Amphitheater Card**:
   - แสดงอัฒจันทร์ 3 มิติ และตัวละคร 3D ที่จะเพิ่มขึ้นทีละตัวทันทีเมื่อพนักงานกดสแกนสำเร็จ
   - กราฟโดนัทสัดส่วนเปอร์เซ็นต์คำนวณสด
3. **Real-time Live Feed & Missing List**:
   - **รายชื่อที่ยังไม่เช็คอิน**: ลดจำนวนลงอัตโนมัติแบบเรียลไทม์
   - **บอร์ดผู้เช็คอินล่าสุด**: แสดงชื่อ, เวลาที่สแกน (เช่น 07:32 น.), คะแนนที่ได้รับ (+10), และตราความปลอดภัย 1:1 Device Binding

## 3. ฟังก์ชันอำนวยความสะดวกสำหรับห้องประชุม (Meeting Display Features)

1. **ปุ่มสลับโหมดมุมมอง (View Toggle)**:
   - **ปุ่ม "โหมดจอคู่สแกนสด (Split Screen Live)"**: เข้าสู่โหมดแสดง QR Code คู่กับ Dashboard
   - **ปุ่ม "โหมดแดชบอร์ดปกติ (Standard)"**: กลับสู่มุมมอง Dashboard เต็มหน้าจอเดิม
2. **ปุ่ม "เต็มหน้าจอทีวี (Full Screen Presentation)"**:
   - ซ่อนแถบเมนูด้านข้างของระบบชั่วคราว เพื่อให้โปรเจกเตอร์หรือทีวีแสดงผลหน้าจออย่างเต็มตา 100% ไม่มีส่วนเกินรบกวนสายตา
3. **การเชื่อมต่อฐานข้อมูลแบบ 0 Delay**:
   - ใช้ Firestore Real-time Snapshots ตรวจจับเมื่อมี Check-in ใหม่เข้ามา แล้ว Render ตัวละคร 3D และตัวเลขสถิติทันที โดยไม่ต้องกดรีเฟรชหน้าจอ

## 4. แผนขั้นตอนการลงมือพัฒนา (Implementation Steps)

1. **สร้างคอมโพเนนต์ `LiveMeetingSplitView.tsx`**:
   - รวมกลไก Live QR Station (ฝั่งซ้าย) และ Dashboard Widgets (ฝั่งขวา)
   - เชื่อมต่อฟังก์ชันตรวจสอบเวลาเปิด-ปิด `getCheckInWindowStatus`
2. **ปรับปรุง `Dashboard.tsx`**:
   - เพิ่มปุ่มสลับมุมมองระหว่าง "โหมดปกติ" และ "โหมดจอคู่สแกนสด (Split Screen)" ในส่วนหัวของหน้า Executive Dashboard
   - เพิ่มปุ่มขยายเต็มหน้าจอ (Fullscreen Browser API) สำหรับเปิดขึ้นจอทีวีห้องประชุม
3. **ทดสอบความต่อเนื่องของข้อมูล (Real-time Test)**:
   - ทดสอบการสแกนผ่านมือถือ แล้วสังเกตการอัปเดตของตัวละคร 3D, ตัวเลข KPI, และรายชื่อคนยังไม่เช็คอินว่าปรับเปลี่ยนทันทีพร้อมกันทั้งสองฝั่งหรือไม่
